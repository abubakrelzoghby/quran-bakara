# جدول قراءة سورة البقرة

مشروع بسيط لعرض جدول قراءة سورة البقرة بنظام تناوب بين 3 أشخاص على مدار 3 أسابيع.

## نظرة عامة

المشروع عبارة عن صفحة ويب بسيطة (HTML/CSS/JavaScript) تعرض جدول قراءة سورة البقرة. يتم تقسيم السورة إلى 3 أقسام، وكل شخص يقرأ قسم واحد في كل أسبوع، مع نظام تناوب يضمن أن كل شخص يقرأ جميع الأقسام خلال 3 أسابيع.

## المميزات الحالية

### الصفحة الرئيسية (`index.html`)
- عرض الجدول الكامل لـ 3 أسابيع
- كل أسبوع يعرض 7 أيام (6 أيام قراءة + يوم تعويض)
- عرض بسيط: "ص X من آية Y إلى Z"
- تفاصيل عند النقر: نافذة منبثقة تعرض التفاصيل الكاملة
- رابط للصفحة الفردية

### صفحة الشخص الفردية (`person.html`)
- عرض الأسبوع الحالي فقط
- جدول الشخص المختار فقط
- أزرار لاختيار الشخص (مريم، يحيى، أحمد)
- حفظ الاختيار في localStorage
- رابط للعودة للجدول الكامل

### التصميم
- تصميم متجاوب يعمل على الموبايل والكمبيوتر
- ألوان مميزة لكل شخص
- جداول واضحة ومنظمة

## هيكل المشروع

```
bakara/
├── dev/                # مجلد التطوير (Development)
│   ├── index.html      # الصفحة الرئيسية
│   ├── person.html     # صفحة الشخص الفردية
│   ├── styles.css      # التنسيقات
│   ├── script.js       # المنطق الرئيسي + البيانات المدمجة
│   ├── person.js       # منطق الصفحة الفردية
│   ├── *.php           # ملفات PHP للميزات الإضافية
│   ├── README.md       # هذا الملف
│   └── .gitignore      # ملفات مستثناة من Git
│
└── main/               # مجلد الإنتاج (Production)
    ├── .vscode/        # إعدادات VS Code (SFTP)
    └── (يتم استدعاء الملفات من GitHub)
```

### ملاحظات حول البنية
- **dev/**: مجلد التطوير - هنا نعمل التعديلات والتجارب
- **main/**: مجلد الإنتاج - يتم استدعاء الكود من GitHub ورفعه على السيرفر
- يتم العمل على branch `base` في مجلد dev (البرانش الأساسي للتطوير)
- يتم العمل على branch `main` في مجلد main للإنتاج

## كيفية الاستخدام

1. افتح `index.html` في المتصفح لعرض الجدول الكامل
2. افتح `person.html` لعرض الجدول الشخصي
3. اختر الشخص من الأزرار في صفحة الشخص الفردية
4. انقر على أي جزء في الجدول لعرض التفاصيل الكاملة

## الميزات المستقبلية (مخطط لها)

1. **صفحة التقسيمات المنفصلة**: صفحة تعرض جميع التقسيمات بغض النظر عن الأسبوع أو الأشخاص
2. **تحديث تلقائي**: زر أو تحديث تلقائي كل جمعة لتغيير الجدول للأسبوع التالي
3. **أشخاص ديناميكيين**: جعل قائمة الأشخاص قابلة للتعديل
4. **عدد أشخاص متغير**: إمكانية تغيير عدد الأشخاص وتقسيم السورة بناءً على العدد

## التقنيات المستخدمة

- HTML5
- CSS3 (مع تصميم متجاوب)
- JavaScript (Vanilla JS - بدون مكتبات)
- localStorage (لحفظ اختيار الشخص)

## ملاحظات مهمة

- البيانات مدمجة في `script.js` - لا حاجة لملف JSON خارجي
- المشروع يعمل بدون خادم - يمكن فتح الملفات مباشرة من المتصفح
- التصميم متجاوب ويعمل على جميع الأجهزة
